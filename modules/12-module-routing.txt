# Module Routing

Use phase-wise routing instead of broad always-on loading.

## Base set

Load for every session:
- `01-orchestrator.txt`
- `02-workflow.txt`
- `07-output-contracts.txt`

## Phase routing

### `CHECKLIST`
Load:
- `07-output-contracts.txt`
- `10-decision-and-intake.txt`

### `DOCS`
Load:
- `03-docs-research.txt`
- `07-output-contracts.txt`
- `10-decision-and-intake.txt`

### `REVIEW`
Load:
- `04-review-rubric-hard-tier.txt`
- `05-review-rubric-soft-tier.txt`
- `07-output-contracts.txt`
- `11-state-machine.txt`
- `15-artifact-handling.txt` when repo hygiene or tooling is in scope
- `16-pre-commit-behavior.txt` when scripts, hooks, or CI config is in scope
- `17-cross-team-requirements.txt` when a finding cannot be resolved in the current repo

### `CONFIRM`
Load:
- `07-output-contracts.txt`
- `08-interaction-layer.txt`
- `10-decision-and-intake.txt`
- `11-state-machine.txt`

### `PLAN`
Load:
- `07-output-contracts.txt`
- `08-interaction-layer.txt`
- `10-decision-and-intake.txt`
- `11-state-machine.txt`
- `15-artifact-handling.txt` when the plan touches build config or environment setup
- `16-pre-commit-behavior.txt` when the plan touches scripts or tooling
- `17-cross-team-requirements.txt` when the plan has dependencies on another repo or team

### `PATCH`
Load:
- `06-fix-and-patch-protocol.txt`
- `07-output-contracts.txt`
- `11-state-machine.txt`
- `15-artifact-handling.txt` when the patch adds or modifies tooling or config
- `16-pre-commit-behavior.txt` when the patch adds or modifies hook config or scripts
- `17-cross-team-requirements.txt` when the patch has unresolved cross-team dependencies

### `TEST_STRATEGY` (BabaTester only)
Load:
- `04-review-rubric-hard-tier.txt`
- `05-review-rubric-soft-tier.txt`
- `07-output-contracts.txt`
- `10-decision-and-intake.txt`
- `13-persona-handoff-contract.txt`

### `HANDOFF` (any persona)
Load:
- `07-output-contracts.txt`
- `13-persona-handoff-contract.txt`

### `BLOCKED` or `FAILURE`
Load:
- `07-output-contracts.txt`
- `09-failure-guards.txt`
- `10-decision-and-intake.txt`
- `11-state-machine.txt`

## Routing rule

At phase change, declare only:
- current phase
- modules active for this phase
- next allowed phase

Do not emit a routing declaration on every normal turn.
